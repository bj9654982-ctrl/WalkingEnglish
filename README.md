# 山径英语 WalkingEnglish

用徒步的乐趣学英语的微信小程序。选择词书和城市，在水彩风 2.5D 山道背词、读故事、遇见小动物，并在营地认识同行旅人。

## 五个底部导航

- **单词**：选词书、继续当前城市的学习路线、到期复习与学习统计。
- **阅读**：三篇原创分级短篇，中英对照、词汇听读与理解题；答对后记录完成。
- **练习**：从当前词书已学单词中抽取最多十题，显示错题与练习统计。没有已学词时提供体验题，不改变登山或复习进度。
- **发现**：手动选择城市，展示对应山峰；武汉的东湖七山移入此处。
- **我的**：学习统计、观察手册、公开资料、关注列表、私信、屏蔽管理和本机记录重置。

## 当前玩法

1. 在「单词」选词书，在「发现」选城市和山峰；切换后保留各自进度，经典混合的武汉路线保留原有七山分配。
2. 进入水彩童话风的 2.5D 山道。单指拖动观景、双指缩放，点击“回到旅人身边”恢复跟随；点击学习，在山道底部打开暖纸色单词卡。
3. 学习卡包含音标、释义、例句和发音。测验答对一个词立即保存并前进；答错会排到队尾重试。
4. 随时收起卡片，已答对的词保留，下次从剩余新词继续。学习时镜头将人物移到上方可见区域；静止场景暂停刷新，答对后短暂播放行走动画。
5. 新词在 24 小时后进入复习，错词在 10 分钟后重试；复习从回忆测验开始。间隔复习成功后，下一次间隔逐步变为 3、7、14、30 天。连续三次间隔回忆成功才计入“稳定掌握”，同日纠错不会增加长期掌握度。
6. 每座山有三个营地。营地对应单词完成间隔复习后点亮；再次到期时提示待复习。首页有到期词入口，登顶后仍可回来复习。
7. 学完本山全部新词，收起面板看角色走完最后一段，再展示包含词书名称的登顶证书。
8. 沿途在 12%、38%、66%、90% 处遇见动物或昆虫。观察并辨认英文名字后记录到手册；收集不会虚增学习进度。六种朋友包括松鼠、蝴蝶、蜗牛、小鸟、萤火虫和瓢虫。
9. 行走到 25%、55%、85% 的营地后可以进入。主动加入后，可查看同营地玩家、关注或私信。尚未配置云环境时明确显示未开放，不产生模拟玩家或模拟消息。

## 微信云开发

社交采用微信云开发，环境 ID 预留在 `miniprogram/config/cloud.js`。云函数、集合权限、索引和双账号联调步骤见 [云开发部署说明](cloudfunctions/README.md)。需要填入环境 ID、建立集合/权限并部署 `trailSocial` 后，才能联调真实多用户功能。学习记录暂存本机，未做云备份或多设备同步。

## 技术与目录

- 原生小程序 WXML / WXSS / JS。
- Canvas 2D 分层绘制：水彩底图、远山、树林、雾气、上坡山道、营地、旅人、近景与萤火。空闲场景最高约 30 fps，像素比例上限 2，树木缓存到离屏画布；后台停绘。
- `utils/cityCatalog.js` / `wordCatalog.js`：城市、稳定山峰 ID 与按城市分配的词表。
- `utils/storage.js`：各词书的学习/复习记录及旧数据迁移。
- `utils/reviewSchedule.js`：间隔复习、错词重试、掌握度。
- `utils/studySession.js`：学习状态机、逐词保存、计时和生命周期；山道面板与旧学习页共用。
- `components/study-sheet/`：山道内的学习面板。
- `utils/trailScene.js`：2.5D 绘制、视差、坡道采样、贴地行走、图片加载和资源释放。
- `assets/trail/watercolor-valley.jpg`：原创水彩背景，1536 × 1024，约 474 KB；当前各城共用底图，色调和树林分布随山峰变化。
- `utils/wildlife.js` / `journal.js`：路线遇见与本机观察、阅读、练习记录。
- `utils/social.js` / `cloudfunctions/trailSocial/`：云端资料、营地到访、关注、私信、屏蔽和举报。
- `pages/`：五个导航页、营地、社交列表、私信、山道与证书。原 `pages/word/` 入口仍兼容。
- `references/watercolor-trail/`：生成原图和提示词。`references/child-of-light/`：Steam 风格参考图，均不打入小程序。
- `references/legacy-3d/`：已退役的 Three.js 适配库及几何代码，仅留档；运行不再依赖 Three.js，也无需安装第三方 npm 包。

## 运行

1. 在微信开发者工具中导入本目录（`project.config.json` 所在目录）。
2. 使用自己的小程序 AppID；直接编译，无需构建 npm。
3. 真机检查卡片滚动、前后台切换、单词发音、山道触摸和分享。

发音使用有道词典音源。发布前需在小程序后台配置对应的合法域名，或接入具备授权的语音服务；开发配置中的关闭域名校验不能替代正式环境设置。

## 检查与回归

安装 Node.js 后运行 `npm test`，或依次运行：

```powershell
node verify.js
node tests/regression.js
node tests/features.js
node tests/social.js
node tests/social-client.js
node tools/check-native.js
```

自动检查覆盖页面和组件完整性、词库分配、v1/v2 存档迁移、逐词保存、错题重试、复习间隔、掌握度与营地、不同词书的进度隔离、前后台计时、页面栈、资源释放、七山上坡路线、人物贴地、多尺寸构图、手势隔离和背景加载失败。

WXML/WXSS 可另用微信开发者工具编译验证。独立调用 WXSS 编译器时，学习面板的 `@import` 依赖 `pages/word/word.wxss` 也需传入。Node 模拟不能替代真机 Canvas 性能、触摸、音频和分享验收。

## 本地视觉预览

运行 `node tools/preview-server.js`，打开 http://127.0.0.1:4173/ 。预览直接复用页面 JS、WXML/WXSS、山道绘制和学习状态机，模拟微信 Canvas、组件与底部导航。支持切换五页、城市、阅读答题、练习、山道学习和动物观察；使用浏览器独立存档，不影响微信存档。浏览器展示云端未配置状态，发音、分享、微信身份和真实私信需在微信内验收。

水彩背景加载失败时仍绘制基础山道；Canvas 初始化失败时保留学习入口和重试按钮。

## 存档升级

- 当前存档为 `we_progress_v3`。新用户默认日常英语；v1/v2 老用户继续经典混合路线。
- 旧山峰 ID 0–6 保持不变，新增城市使用 7–21，已有 v3 存档自动补齐空白城市，不复制假进度。城市选择用 `we_city_v1`，阅读/练习/观察记录用 `we_journal_v1`。
- 已学单词会按实际词表分配导入对应词书，旧数据中重复的单词只计一次。旧版全通关的 370 次记录对应 225 个不同单词，经典路线仍可补学剩余 145 词。
- 原始 v1/v2 存档保留备份。v2 经典路线的逐山计时完整保留；新词书中导入的历史记录缺少对应计时，证书会说明“旧记录未完整计时”。
- 旧存档没有复习证据，迁移后不会直接标为掌握，会安排复习。
- 有效学习时间包含前台学习/答题和中途退出前的时间，排除后台、结果页和山道停留。
- 「我的 → 清空本机学习记录」清除全部词书、城市、阅读、练习与观察记录及旧备份，不删除云端社交数据。
