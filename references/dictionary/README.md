# 点词查义与生词本

更新日期：2026-10-25。

## 使用方式

- 在小程序的论文标题、正文、摘要、学习例句、练习反馈例句、动物相遇句子或营地消息中，轻点英文单词。
- 打开「单词释义」页，查看中文词义、音标（词典提供时）和原文片段；点击「加入生词本」。可以填写自己的笔记。
- 「我的 → 我的生词本」显示已收藏的单词，可按单词、释义、来源或笔记搜索，按收藏时间/字母排序，听发音、编辑笔记或确认移除。
- 词条大小写统一去重，保留收藏时间、原句与来源。再次在新语境收藏同一个词，会更新该词的原句及来源。
- 查词不修改登山、练习或阅读进度；返回论文仍停留在原页面。释义页内继续查词使用页面替换，避免无限堆叠页面。

## 数据与边界

词典来自 [ECDICT 官方仓库](https://github.com/skywind3000/ECDICT)，按仓库提供的 MIT 许可证使用。原始 CSV 和许可证保存在本目录，运行包中也包含 `dictionary-LICENSE.txt`。

本次从语料匹配词和 BNC 常见词中构建了 **13,720** 个英汉词条，另外优先使用已有学习词库，补充常用缩写及 IQA / SSIM / SROCC 等图像质量术语。不是联网逐句翻译，也不保证人名、论文方法缩写、OCR 片段都有释义；未收录词会明确显示缺失，仍可补充笔记并收藏。词典释义需结合上下文选择。

四个词典分包总计约 **1.17 MB**。第一次加载相应分包需要网络，查词内容不发送给第三方翻译服务。无需填写云开发环境 ID。

生词本使用本机 `we_vocabulary_v1` 存储，最多 2,000 条，受微信本机存储容量限制；失败时不会提示保存成功。暂不跨设备同步，清除小程序数据会丢失；应用内「清空本机学习记录」保留生词本。单词移除需要用户确认。

发音继续使用现有语音服务：已收录词使用本地音频，其余词、原句需要已配置的 `trailSpeech` 云端服务。词典词义不依赖语音配置。

原始 PDF 使用系统文档查看器，点词功能适用于小程序内的文字阅读版。

## 构建和验证

重新构建词典：`python tools/build-dictionary.py`。输入文件 `references/dictionary/ecdict.csv`，数据来源及 SHA-256 见 `build-report.json`。构建脚本保留现有论文和音频分包。

实现：`utils/wordLookup.js`（分词与上下文）、`utils/dictionary.js`（分包查义）、`utils/vocabulary.js`（存档）、`components/lookup-text/`（点词组件）、`pages/lexicon/`（释义页）、`pages/vocabulary/`（生词本）。
