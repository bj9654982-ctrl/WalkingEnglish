# 微信云开发接入

代码已准备好；当前没有环境 ID，也没有创建、部署远程环境或发送真实私信。本机单词、阅读、练习、城市与生物手册可独立使用。

## 部署步骤

1. 在微信开发者工具打开本项目，选择与小程序 AppID 关联的云开发环境。将环境 ID 填入 `miniprogram/config/cloud.js` 的 `envId`，重新编译。不要填写 AppSecret 或其他密钥。
2. 在云开发数据库创建以下七个集合：`trail_profiles`、`trail_visits`、`trail_follows`、`trail_conversations`、`trail_messages`、`trail_blocks`、`trail_reports`。
3. **每个集合均设置为客户端不可读、不可写**，自定义权限内容见 `database-permissions.json`。所有读写必须经过 `trailSocial` 云函数。不要设置为“所有用户可读”。管理员服务端 SDK 通过云函数访问，函数自行做身份和成员检查。
4. 按 `database-indexes.json` 建索引。`members` 是字符串数组，使用支持数组字段的索引；名单按 `_id` 稳定翻页，会话每页按更新时间展示。消息按 `conversationId + seq` 排序，分别支持历史和新增读取。
5. 在开发者工具中右键 `cloudfunctions/trailSocial` → **上传并部署：云端安装依赖**。已固定 `wx-server-sdk` 为 `4.0.2`，前端无需构建 npm。云函数名必须是 `trailSocial`。建议将函数超时设置为 20 秒，使用控制台支持的 Node.js 运行时。
6. `trailSocial/config.json` 已声明 `security.msgSecCheck`。确认小程序具有文本内容检查权限；昵称、简介和私信均须检查通过才能写入。服务不可用或返回复审/拒绝时，界面保留草稿并提示重试，不会绕过检查。
7. 用两个真实微信测试账号完成下面的联调。云端调试器手写的 `OPENID` 不等同于真实小程序调用；身份以 `getWXContext().OPENID` 为准。

更新词书或山峰分配后，先运行 `node tools/build-cloud-routes.js`，再重新部署函数，使服务器的营地阈值与客户端一致。

## 双账号联调

- A、B 分别到「我的」保存昵称和头像；公开信息只有头像、昵称、简介和营地到访时间，不包含微信号、OPENID 或定位。
- 两个账号在同一座山分别学到营地阈值（25%、55%、85%，词数向上取整）。点击营地后主动「加入营地」，双方应出现在名单中。未加入营地的 C 账号不能读名单。
- A 关注 B，回到「我的 → 我关注的旅人」应可见 B。再次点击关注应取消。重新进入或重复提交不会产生重复关系。
- A 从营地或关注列表给 B 发一条私信，B 从「我的 → 营地私信」打开会话。检查新消息标记、阅读状态、断网重试、30 条以上历史消息的分页。
- B 屏蔽 A 后双方不能读取或发送会话消息；A 不应再出现在 B 的营地名单中。B 在「屏蔽管理」解除后可恢复已有会话。
- 举报保存到 `trail_reports`，由环境管理员在控制台查看并处理；目前没有独立的后台审核界面。
- 切后台至少 30 秒，确认聊天停止轮询，回来后补取消息；学习计时与山道动画也应暂停。

## 实现与边界

- 云函数只信任服务端微信身份，公开 UID 为 OPENID 的 SHA-256 截断值；忽略客户端传来的 sender / owner。公开 UID 不作为访问权限凭证。
- 会话只供两位成员访问。首次建立关系需要共享营地，或发送者已经关注对方；已有会话保留，屏蔽会禁止访问。
- 每条私信最多 500 字，连续发送间隔至少 2 秒。消息 ID 幂等，序号、消息与会话摘要在数据库事务里一起保存；网络重试不会重复发送。
- 页面可见时每 5 秒补取新消息，隐藏后停止；未读游标只在有新消息时更新。没有推送通知或离线微信提醒。
- 营地到访验证当前词书、所属词表、不重复已学数与阈值。**学习过程目前仍在本机，提交的是客户端进度，不具备服务端防作弊凭证。** 本版本不提供竞技排行榜、奖励兑换或真实位置签到。
- 本机清空学习记录不会删除云端到访、关注、消息和资料；它也不是退出营地或账号注销。云端学习备份、多设备学习同步、退出营地/账号注销流程是后续独立功能。
- 所有城市共用原创水彩底图，通过色调、树林布局与生物组合区分；不是实地地形导航，也不表示特定物种必然分布于该城市。
- 线上使用前仍须完成真实环境权限、内容检查、消息与真机生命周期联调。现有本地模拟测试不能代替这些步骤。

接口实现参照 [微信云开发 Server SDK](https://github.com/wechat-miniprogram/wx-server-sdk)、[CloudBase 事务文档](https://docs.cloudbase.net/database/transaction) 与[微信云函数接入说明](https://docs.cloudbase.net/en/recipes/add-cloud-function-wechat-miniprogram)。
